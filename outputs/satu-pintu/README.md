# Satu Pintu

Direktori 771 layanan, portal, aplikasi, layanan daerah, dan kampus Indonesia.

## Pakai lokal

Buka `index.html` langsung di browser. Pencarian, filter, simpan, detail, dan ekspor CSV berjalan tanpa server. Mini-game memuat Three.js dari CDN sehingga memerlukan koneksi internet saat pertama dibuka.

## Unggah

Unggah seluruh isi folder ini ke hosting statis. `index.html`, `style.css`, `app.js`, dan `catalog.js` harus tetap satu folder.

## Data

- `layanan_indonesia_v2.csv`: data lengkap 771 baris.
- `catalog.js`: data tertanam untuk website.
- Status tautan adalah hasil pemeriksaan pada 21 Oktober 2026, bukan jaminan permanen.
